# Mountcraft Demo

Windows demo of **Mountcraft**, a mount system for multiplayer games in Unreal Engine 5.6 to 5.8: getting on and off
with animation, four gaits with stamina, flying mounts, passengers, gear that changes speed and health, and attacks
from the saddle. The demo is the plugin's own example map, packaged as a Shipping build with UE 5.8.

**Download:** [MountcraftDemo_Win64.zip](https://github.com/filipetessaro/mountcraft-demo/releases/latest/download/MountcraftDemo_Win64.zip)
(527 MB). Windows 64-bit, DirectX 12 with Shader Model 6. No engine needed.

Unzip it anywhere and run `MountLab.exe`. You start in a meadow, in a valley 2 km across, beside two horses, a stag, a
bull, a mule, a dire wolf, an alpaca and a winged horse. There are three logs to jump, a ramp, and training dummies to
the right of the path.

| Key | Gamepad | What it does |
|---|---|---|
| E | Left face button | Get on the mount in reach, get off |
| H | D-pad up | Call your last mount |
| WASD, mouse | Sticks | Steer, look around |
| Shift, Ctrl | RB, LB | Faster or slower gait: walk, trot, canter, gallop |
| Space | A | Jump; on the winged horse, take off |
| Left mouse | Right trigger | Swing the sword |
| Right mouse, held | Left trigger | Aim the bow, left mouse shoots |
| F | Right face button | The mount kicks back |
| R | Top face button | The mount rears up |
| C, arrows | | The stable: coat and gear of the mount you ride or stand by |
| Alt+F4 | | Quit |

The demo runs alone on one machine. The plugin is replicated and predicted, measured with three players at 150 ms of
lag and 5% packet loss.

The animals are from Quaternius (CC0), the scenery from Poly Haven (CC0), the HUD's frames from Kenney (CC0) and its
font is Cinzel (SIL Open Font License). The mannequin is Epic Games' template content.
